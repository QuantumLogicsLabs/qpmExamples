One language.
Every syntax you already know.

Quantum is a dynamically typed scripting language that accepts Python-style, JavaScript-style, and C-style syntax — in the same file. Lexer → parser → type checker → single-pass bytecode compiler → stack-based VM.

Why Quantum

Built to run anything, ship as one file.

⚡

Multi-syntax front end

.sa, .js, .py, .rb, .c, and .cpp all compile through the same pipeline — no node, python, or gcc required.

🛠️

Bytecode VM

A single-pass compiler emits bytecode for a stack-based VM, with closures, upvalues, and first-class pointers.

🔍

Warnings, never blocks

The type checker flags issues without stopping you — dynamically typed means dynamically typed.

📦

Standalone .exe bundling

quantum hello.sa compiles, bundles the bytecode onto a stub runtime, and runs the result — one file, no install.

🌐

qpm, a real npm client

A standalone package manager that talks to the npm registry directly — no npm or Node.js required to install.

✨

REPL included

Run qrun with no arguments to drop straight into an interactive Quantum session.

Same file, three dialects

Write it the way you already think.

fibonacci.sa 
def fib(n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}

for i in range(0, 10):
    print(fib(i))

# Python-style, C-style, JS-style — pick what fits the line.

Package management

qpm installs real npm packages. No npm required.

A standalone binary that talks to registry.npmjs.org directly — resolves semver ranges, downloads tarballs, and extracts them into node_modules itself.
